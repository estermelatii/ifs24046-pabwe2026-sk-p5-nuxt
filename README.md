# ifs24046-pabwe2026-p5-nuxt — Delcom Cash Flow

Studi kasus **Cash Flow** (Nuxt + TypeScript + Pinia).

## Setup
```bash
bun install
bun run dev
```

## Env
```
NUXT_PUBLIC_DELCOM_BASEURL=https://open-api.delcom.org/api/v1
```

## Routes
- `/auth/login`, `/auth/register`
- `/` dashboard arus kas
- `/cash-flows/:cashFlowId` detail
- `/users`, `/profile`

API: https://open-api.delcom.org/docs/1.0/api-cash-flows
